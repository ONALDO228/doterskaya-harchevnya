# Дотерский харч

Учебный сайт-рецепт на чистом HTML, CSS и JavaScript. Без сборщиков, без библиотек —
файлы открываются в браузере как есть.

## Структура

```
index.html      главная: карточки рецептов + кнопка «что готовим наугад»
recipe.html     страница рецепта (борщ)
bliny.html      страница рецепта (блины)
salat.html      страница рецепта (цезарь)
carbonara.html  страница рецепта (карбонара)
style.css       все стили: переменные, флекс-карточки, грид, адаптив
script.js       массив рецептов + случайный выбор по клику
img/            картинки блюд
```

## Как запустить локально

Двойной клик по `index.html`. Никакой сборки не требуется.

## Публикация

GitHub Pages: Settings → Pages → Branch: `main`, folder: `/ (root)`.
Сайт статический, сборка не нужна.
